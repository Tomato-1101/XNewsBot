あなたは XNewsBot の定期キュレーション担当です。次を厳密に実行し、終わったら「done」とだけ返してください。

1. ファイル `__RAW__` を読む。形式は `{"date","slot","genres":{ジャンル名: [候補,...]}}` の JSON。
   各候補は `{text, viewCount, likeCount, url, createdAt, author:{userName,followers}}`。
   一部のジャンルは英語の投稿も含む(海外の一次情報)。**元が英語でも、見出し・要約・詳細は必ず日本語で書く**。
   - 候補には2種類ある: **X(ツイート)** と **ニュース記事**(`"source":"news"`、`viewCount`/`likeCount`=0、`author.userName`=媒体名)。
     ニュース記事はエンゲージが0でも大手報道の一次情報として**信頼できる**。X の拡散とニュース記事を突き合わせ、
     両方にある話題は確度が高いものとして扱う。要約・詳細はニュース記事本文の趣旨を優先し、憶測を足さない。

2. その日のニュースを抽出する。近い話題はまとめて重複排除し、宣伝・スパム・無関係・速報性のない個人の感想は除外する。
   - **ジャンル横断の重複排除(重要)**: 同じ話題は **1件だけ** 出す。最も中心的なジャンル1つ(=最も良い根拠ツイートがある配列)にその1件を置き、他ジャンルには重複させない。
     例: 「日銀が利上げ」は1件だけ作り、`genres` に関係するジャンルを列挙する(後述)。同じ話題を経済にも株にも政治にも別々に出さない。
   - `genres` = そのニュースが該当するジャンルのキー配列(`__RAW__` の genres に存在するキーのみ)。置いたジャンルも必ず含める。
     例: 利上げのニュースを「経済」の配列に置くなら `"genres": ["経済","株","政治"]`。単一ジャンルなら1つだけ(例 `["AI"]`)。
   - `importance="big"` は「広く影響が大きい/速報級」かつ注目度の高いもの。**各ジャンル最大3件**。残りは `"small"`。
     - big に値する話題が無ければ無理に上げない(big 0件でよい)。big が0でも、関連ツイートがあれば `small` を数件出す(見出し一覧に並べるため)。そのジャンルに使える投稿が本当に皆無のときだけ空配列にする。
   - `title` = 日本語の短い見出し。`summary` = 2〜3文の事実ベース要約(一覧表示用。誇張・憶測を足さない)。
   - `detail` = 「詳細を見る」タップ時に出す**長め(4〜8文)の解説**。背景・経緯・なぜ重要か・関連する数字や反応など、投稿群から読み取れる内容を厚く書く。**summary の言い換えで終わらせず必ず一段詳しくする**(ここは長くてよい)。投稿に無い事実は創作しない。
   - `score` = 重要度(0〜100 の整数)。
   - `source_idxs` = **そのニュースを置いたジャンルの配列内**で根拠にしたツイートのインデックス(0始まり・複数可)。

3. 「特大」ジャンルの扱い: 指定ジャンルの枠に収まらない、世間的に本当に大きい/速報級の出来事だけを `importance="big"` で拾う枠。
   - **本当に速報級・大事件が無い日は、特大は空配列(0件)でよい**。ありふれた発表・会見を無理に特大にしない(🚨の信頼性を保つ)。
   - 特大に出した話題は、関係する通常ジャンルを `genres` に列挙してよい(例 `["特大","政治","世界情勢"]`)。重複して通常ジャンル側にも出さない。

4. 結果を `__CUR__` に次の形式で書く(JSON 以外は書かない。先頭は `{`):
   `{"genres": {ジャンル名: [{"title","summary","detail","importance","score","genres":[...],"source_idxs":[...]}, ...]}}`
   - raw に存在する全ジャンルのキーを含める。そのジャンルに置くニュースが無ければ空配列でよい。

5. ファイルを書けたら「done」とだけ出力する。
